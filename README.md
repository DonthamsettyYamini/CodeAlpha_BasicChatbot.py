# Basic Chatbot

A simple rule-based chatbot developed in Python. The chatbot responds to predefined user inputs such as greetings and basic questions.

## Features

* Responds to "hello"
* Responds to "how are you"
* Exits when "bye" is entered
* Handles unknown inputs

## Technologies Used

* Python 3

## How to Run

```bash
python chatbot.py
```

## Example

```text
You: hello
Bot: Hi!

You: how are you
Bot: I'm fine, thanks!

You: bye
Bot: Goodbye!
```
